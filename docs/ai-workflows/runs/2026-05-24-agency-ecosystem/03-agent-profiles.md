# 03 — Agent Profiles

## `agent_profiles`

- `userId` (1:1 agent)
- Optional `agencyProfileId`
- `slug`, bio, specializations, regions
- Privacy: `showPhone`, `showEmail` (default false)
- `status` moderation gate

## Trust indicators (real data)

- Agent trust score from `agent_trust_scores`
- Response reliability from CRM first-response ratio
- Listing count + avg quality from trust scores
- No user-submitted ratings
