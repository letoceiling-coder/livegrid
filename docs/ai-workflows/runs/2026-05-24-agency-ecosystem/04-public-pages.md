# 04 — Public Pages

## Routes

- `/agency/:slug` → `PublicAgencyPage`
- `/agent/:slug` → `PublicAgentPage`

## API

- `GET /ecosystem/agencies/:slug`
- `GET /ecosystem/agencies/:slug/listings`
- `GET /ecosystem/agents/:slug`
- `GET /ecosystem/agents/:slug/listings`

## UX

- Trust chips, listing carousel, sticky contact CTA (mobile)
- Premium themes from billing plan (`resolvePublicTheme`)
