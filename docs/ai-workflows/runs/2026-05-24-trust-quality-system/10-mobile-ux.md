# 10 — Mobile UX

## Public Badges

- Compact mode: icon-only pill on listing cards (360px safe)
- Detail page: max 3 badges, small text (10px), subtle colors
- No visual overload — badges capped at 2 on cards, 3 on detail

## Admin Trust Center

- Horizontal scroll filter tabs
- Stacked list rows min-height 56px
- Summary grid 2 cols mobile → 4 desktop
