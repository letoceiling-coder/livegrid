# 10 — Mobile UX

## Task Center (`AdminTasksPage`)

- **360px-safe**: horizontal filter chips scroll, no overflow
- **Swipe complete**: left swipe reveals green "Готово" — release past 60px completes
- **Compact cards**: priority badge, truncated body, min-height 72px
- **Sticky action bar**: fixed bottom on mobile — links to overdue requests + callbacks inbox
- **Touch targets**: min 40–44px on buttons and filters
- **Callback quick action**: tel: link on CALL_CLIENT tasks

## Request Detail

`RequestAutomationPanel` uses responsive padding and collapsible history for small screens.

## Ops Center

Automation metrics grid: 2 cols mobile → 6 cols desktop.
